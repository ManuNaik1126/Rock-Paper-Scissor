# 🎮 Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript. Play against the computer and try to win by choosing the right move!

## 📌 About the Project

This project is a browser-based implementation of the classic Rock Paper Scissors game. Players choose Rock, Paper, or Scissors, and the computer randomly selects its move. The game compares both choices and displays the result.

## ✨ Features

- Interactive Rock, Paper, and Scissors choices
- Play against the computer
- Random computer selection
- Automatic winner detection
- Displays the result of each round
- Simple and user-friendly interface
- Score tracking (if implemented)
- Option to restart the game (if implemented)

## 🛠️ Technologies Used

- HTML — Structure of the game
- CSS — Styling and layout
- JavaScript — Game logic and interactivity

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/ManuNaik1126/rock-paper-scissors.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.
4. Choose Rock, Paper, or Scissors and play!
